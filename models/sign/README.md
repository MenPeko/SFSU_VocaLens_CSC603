# Sign models

This directory holds model weights and other training artifacts derived from ASL Citizen. They are local-only.

The dataset is covered by the Microsoft Research License Terms. That text does not define whether trained weights are a modification of the data, and it forbids distributing modifications. Until that is explicit, files written here stay on this machine. The root `.gitignore` ignores everything in this directory except `README.md`.

Use stays inside non-commercial, non-revenue-generating research. Where the dataset is named, cite Desai et al. 2023 (`desai2023asl` in `docs/DATA_LICENSES.md`).
